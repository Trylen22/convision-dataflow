# ConVision · data flow

Animated walkthrough of the ConVision vision-guided conveyor sorter (ICET 4751 capstone): the camera and Jetson Nano classify each part, the class travels to a PLC tag, and the PLC drives the diverter into the matching bin.

**Watch it:** https://trylen22.github.io/convision-dataflow/

Works on phones: tap to pause, pick a chapter to jump, turn the phone sideways for full screen.

`index.html` is generated by `build-mobile.py` from the capstone's `convision-dataflow.html`; edit the source and rebuild rather than editing it here.
